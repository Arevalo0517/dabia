Uso de la información

Para qué usamos estos datos.

La información se utiliza exclusivamente para responder a tu solicitud y, si tiene sentido, iniciar una conversación sobre un posible proyecto.

1
Responder a tu mensaje

Contactarte para agendar el diagnóstico o resolver tu consulta.

2
Evaluar el proceso

Entender el área o flujo que mencionas para preparar la conversación.

3
Mejorar el sitio

Detectar errores, problemas de uso o información que falta.

Compartición

Con quién compartimos tu información.

DABIA no vende ni comercializa datos personales. Solo compartimos información con proveedores estrictamente necesarios para operar el sitio.

⚙

Proveedores de infraestructura

Servicios de hosting, correo y analítica necesarios para operar el sitio.

Obligaciones legales
